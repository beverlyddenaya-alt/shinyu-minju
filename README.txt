SHINYU × MINJU — fictional couple AU website

UPLOAD TO GITHUB (phone):
1. Open your shinyu-minju repository > Add file > Upload files.
2. Upload index.html, style.css, script.js AND the assets folder/files. Do NOT upload the ZIP as the website itself.
3. Commit changes.
4. Repository Settings > Pages > Build and deployment > Source: Deploy from a branch.
5. Branch: main, folder: /(root), Save.
6. Wait 1–3 minutes. GitHub will show the public Pages URL.

This is fan-made fiction/AU and does not claim a real relationship.
